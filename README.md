# Painel de Insights de Atendimento

> **Demo de portfólio independente.** Não representa trabalho contratado, dados de cliente, integração produtiva ou resultado comercial.

Painel estático para visualizar métricas ilustrativas de atendimento. Todos os dados são fictícios e processados localmente no navegador.

## Funcionalidades demonstradas

- Métricas e KPIs de atendimento fictícios
- Gráficos de desempenho por período
- Filtros por data e categoria
- Design responsivo e acessível
- Sem dados reais ou integrações externas

## Segurança

- Dados 100% fictícios
- Sem requisições externas
- Sem armazenamento sensível
- Processamento local exclusivo

## Tecnologias

- HTML5, CSS3, JavaScript ES6+
- Módulos nativos
- Node.js para testes

## Executar

```bash
npm test && npm run review
```
